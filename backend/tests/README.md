# Backend tests

Run from `backend` using the project's existing Python environment. No extra
dependencies are required beyond `requirements.txt`.

## PostgreSQL integration tests

Provision a **separate PostgreSQL 17 database** named `soyle_test` and a test role
that can connect to it and create schemas. Do not use the application's database.
Set `TEST_DATABASE_URL` explicitly; these tests never fall back to `DATABASE_URL`.
Passwords containing special characters must be URL-encoded.

```powershell
Set-Location C:\smart-communication\backend
# Replace the placeholders with credentials for the dedicated test database.
$env:TEST_DATABASE_URL = 'postgresql+asyncpg://<test_user>:<encoded_password>@localhost:5432/soyle_test'
python -m pytest tests -q
Remove-Item Env:TEST_DATABASE_URL
```

The harness rejects non-asyncpg URLs and database names without the `_test`
suffix. Each test creates a random schema, applies real Alembic migrations and
drops only that schema in cleanup. The PostgreSQL search path excludes `public`.
No `Base.metadata.create_all()` is used. An interrupted process can leave a
`soyle_test_<uuid>` schema in the dedicated database; normal completion removes it.

Without `TEST_DATABASE_URL`, PostgreSQL integration tests are skipped. Existing
HTTP health tests require no running database:

```powershell
python -m pytest tests/test_health.py -q
```

The migration test exercises `0001 -> head -> 0001 -> head`, checks the revision
and table names, and compares migrated tables with ORM metadata.

## Model conventions

- `User.child_links` and `Child.user_links` expose `ChildUser` association objects.
  `Child.card_links` and `Card.child_links` expose `ChildCard` objects, including
  ordering and favorite status. Load relationships explicitly using `selectinload`
  or `joinedload`; unloaded access raises rather than issuing implicit async I/O.
- UUIDs are generated by the ORM. Required roles have no implicit default.
- Email uniqueness uses PostgreSQL's unique index on `lower(email)`; the original
  spelling is retained. Association pairs use composite primary keys.
- Timestamps are PostgreSQL `TIMESTAMP WITH TIME ZONE` instants. `created_at` and
  `updated_at` default to database `now()`; ORM updates refresh `updated_at` using
  `now()`. Direct SQL updates must set `updated_at` explicitly. For UTC display,
  use a UTC database session or convert the returned aware datetime to UTC.
- Removing a user, child or card cascades only to the corresponding association
  rows. Categories containing cards cannot be deleted.
- `password_hash` accepts an existing password hash; hashing belongs to future
  authentication work. There is no plaintext password column or authentication
  API. Child notes are for communication context, not medical diagnoses.
